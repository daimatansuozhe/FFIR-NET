# Data info

`price_with_indicators`是每只股票加上技术指标with label的数据

`tweet_sentiment_my`是使用微调后的FinBERT进行情感分析任务所得到的每个句子的情感得分
`tweet_sentiscore_daily_my`是每日情感得分
> ist_pos   ===>    pos/total\
> ist_neg   ===>    neg/total\
> ist   ===>(pos-neg)/total
---
`price_with_n_indicators`n表示按特征重要性排序的前n个特征；该文件夹防止每只股票的前n个技术特征
